# AI for GNC

A structured learning and project roadmap for applying machine learning, deep
learning, physics-informed neural networks, and reinforcement learning to
guidance, navigation, and control (GNC) and autonomous aerospace systems.

## Roadmap

### Machine learning foundations

1. Mathematical Foundations for Machine Learning
2. Machine Learning Fundamentals
3. Data Preparation for Engineering ML
4. Regression for Aerospace and GNC
5. Classification and Fault Detection
6. Unsupervised Learning and Anomaly Detection

### Deep learning

7. Neural Networks from First Principles
8. PyTorch Fundamentals
9. Deep Neural Networks
10. Time-Series and Sequential Models

### Machine learning for GNC

11. Machine Learning for System Identification
12. Surrogate Models and Residual Learning

### Physics-informed neural networks

13. Automatic Differentiation for Physics
14. Physics-Informed Neural Networks Fundamentals
15. PINNs for Dynamical Systems and ODEs
16. PINNs for PDEs and Inverse Problems

### Reinforcement learning and control

17. Decision Making and Reinforcement Learning Foundations
18. Markov Decision Processes and Classical RL
19. Deep Reinforcement Learning
20. Learning-Based Control for GNC
